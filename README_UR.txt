سیلز اور منافع — Native Android پروجیکٹ

یہ پروجیکٹ WebView/HTML ایپ نہیں ہے۔ اس میں Java Android Activity، Android UI widgets اور SQLite ڈیٹا بیس استعمال ہوا ہے۔

موجودہ خصوصیات: اردو نیویگیشن، پہلے سے شامل دکانیں اور آئٹمز، نئی سیل، ہر آئٹم کی مقدار +/−، دکاندار کے مطابق قیمت تبدیل کرنا، خودکار منافع، حالیہ سیلز، دکان وار سیل/منافع، آئٹم شامل/ترمیم/حذف، بنیادی رپورٹس۔ خرید قیمت سیل اسکرین پر نہیں دکھائی جاتی۔

APK ابھی اس repository میں نہیں ہے؛ GitHub Actions کے ذریعے compile ہوگی۔ یہ پہلا Native build draft ہے۔ مکمل استعمال سے پہلے حقیقی Android ڈیوائس پر compile، install اور حسابات کی جانچ ضروری ہے۔
